# Deferred GPU adapter prototype

This code is preserved from the original Halley UI extraction. It is excluded
from the published crate and is not compiled by this package. Halley retains its
GPU implementation and Smithay revision. Future integration must adapt these
sources to the then-current core API and explicitly chosen Smithay version.

See `../docs/reintegration/README.md` for the saved migration and the dependency
constraint. Historical GPU test results apply to the original pinned prototype,
not to an independently published backend.
